**Unlucky Client 2.3.1** — MC 26.2 / Fabric. 190 modules.

**Render**
- Added Tracers — a standalone module for players, hostile and passive mobs, items, vehicles, projectiles and other loaded entities. Includes friend handling, per-mob filters, range and line-of-sight controls, configurable screen and body anchors, optional stems, and type, distance, static or theme colours.

**World**
- Printer now separates **Print only** from **Automatic fly**. Print only is the new default and places schematic blocks already in reach without moving the player, changing Litematica layers, surveying stashes or handling shulker supplies. Switching modes live releases every automation-owned state cleanly; existing Printer configs remain compatible.

**Movement**
- Added `.vclip up <blocks>` and `.vclip down <blocks>`, plus signed shorthand such as `.vclip -3`, for short vertical clips. Invalid, mounted and over-10-block moves are rejected instead of creating a one-frame client/server desync.

**Player**
- Reworked AutoEat to use the selected food directly instead of holding the shared right-click key. It can now eat while an inventory or container is open without closing the screen, opening the block under the crosshair, placing a held block or shuffling the main hand out of the offhand's way. Interrupted meals retry once and then yield cleanly.

**Fixes**
- Fixed the brief freeze some players saw when opening containers. InventoryInfo's optional byte-size line no longer serializes a component-heavy hovered item on the render thread: work is asynchronous, bounded to one active and one latest request, and stale results are discarded. Byte size now defaults off.
- InventoryInfo's ender-chest preview now recopies slots only when the menu revision or contents actually change, removing unnecessary per-tick stack copies while the screen is open.
- Fixed the first-run Offhand migration accepting only legacy primitive settings. Bundled defaults and older profiles now both load through the canonical setting format.
