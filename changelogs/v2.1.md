**Unlucky Client 2.1** — MC 26.2 / Fabric.

**Combat**
- Added LegitMaceKill — amplifies mace damage only while you are genuinely falling.
- Added BlatantMaceKill — spoofs a lethal mace fall while you stay on the ground.
- Added MaceCombo — chains mace smashes by relaunching with wind charges.
- Improved Criticals: thorns retaliation no longer throws you off. The stale vertical velocity the server echoes while the spoof says airborne is rebuilt from vanilla's grounded knockback formula; horizontal knockback and unrelated motion packets are untouched.

**Movement**
- Added EventlessFly — direct-packet flight that bypasses ordinary movement events.
- Added BoatFly — fly the boat you are riding with WASD, jump and sprint.
- Added EntityControl — steer ridden mobs without a saddle or steering item.
- Added EntitySpeed — control the speed of ridden living entities.
- Added WindChargeJump — jumps when you throw a wind charge underneath yourself.
- Added Phase — move through blocks, optionally deferring the server teleport.
- Rebuilt Velocity with a multiplier per force: knockback, explosions, liquid flow, entity push and the fishing-rod pull, each with its own horizontal and vertical scale. 0 cancels that force, 1 is vanilla, and movement you already had is preserved rather than erased.

**Player**
- Added HotbarLoadout — restores a saved creative hotbar (Ctrl+1..9) into survival with every data component intact. Three methods: Creative spoof, Script run, App command.
- Added DonkeyRitual — the donkey exploit.
- Added InfiniteInteract — temporarily packet-steps into range for distant actions.

**Render**
- Added Trajectories — predicts the flight path of throwable items while held.
- Added PearlChecker — labels pearls and predicts where they will land.
- Added NBTTooltip — shows raw item data components and copies them from tooltips.

**World**
- Added VillagerRoller (by FlexCoral) — rerolls librarian books automatically.

**ClickGUI**
- Added a search panel to Future: type to filter every module, with descriptions on hover. Draggable and scrollable.
- Added button settings, so a module can expose a one-shot action in its option list.
- Long labels in Future's narrow columns now ping-pong within their slot instead of being cut off.

**Tablist**
- Markers now insert after the username without disturbing server styling, so a server colouring the name and its custom HP keeps both.

**Alts**
- The Azure client id used by the Microsoft flow can be overridden in `alts.json` for your own app registration. The default is unchanged.
