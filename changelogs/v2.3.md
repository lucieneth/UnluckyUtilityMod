**Unlucky Client 2.3** — MC 26.2 / Fabric. 189 modules.

**Combat**
- Added HoleFill — fills the hole a target is standing in, on the shared placement executor.
- Added Burrow — puts a block inside your own hitbox, from the same executor.
- Added AutoTrap — encases a target in obsidian; single, double and quad presets, and a custom set that cannot generate duplicate positions.
- Improved Surround: rebuilt on the shared `PlacementExecutor`, so it, HoleFill, Burrow and AutoTrap spend one placement budget between them instead of four.

**Movement**
- Added Step — client-side step height through `LivingEntity.maxUpStep`, so there is no attribute modifier left behind on disable.
- Added ReverseStep — steps down as smoothly as vanilla steps up.
- Added SafeWalk — never walk off a ledge; joins the hook Scaffold already owned.
- Added Parkour — jumps automatically at the edge of a block.
- Added NoPush — ignore pushes from entities, flowing water and blocks, each separately.
- Added AutoWalk — key-driven travel with an optional locked heading and auto-jump. Deliberately not a pathfinder.
- Added ElytraRecast — re-deploys the elytra the instant the server takes it away.
- **Rebuilt AutoSprint on the sprint key.** It used to write the sprint flag directly, which the server corrects through the shared-flags byte — one packet a tick for as long as you were moving, with the sprint visibly flickering underneath. It now holds `keySprint` and lets vanilla start, cancel and re-take the sprint on its own schedule. Measured on the same staircase: 480 sprint packets over 2228 ticks became 60 over 737. Omni-directional sprint still writes the flag, because a key cannot express "sideways".
- Improved ElytraFly: brakes before your current flight path reaches a solid block, with separate look-ahead distances for velocity and heading.

**Render**
- Added VoidESP — holes through the bedrock floor, and through the nether roof. Adjacent columns are merged into rectangles, because a two-wide gap is one hole.
- Added TunnelESP — finds dug corridors by shape rather than by block list; a corridor is drawn as one long box along its own axis.
- Added EntityOwner — the name of whoever owns that pet or pearl, friends coloured as everywhere else.
- Added ItemHighlight — picks chosen items out of any container, the player inventory and the creative tabs.
- Added CameraTweaks — third-person distance, clipping through blocks, and scroll-to-zoom. Replaces ViewClip, which was the same hook under another name. Freelook stays its own module.
- Added HoleESP — marks holes a crystal cannot reach into, coloured by what the walls are actually made of.
- Added ItemESP — dropped items, with rarity and stack-count filtering.
- Added BetterTab — a wider, sortable tab list with pings, gamemodes and friend marks.
- Added BlockOutline — restyled block selection: colour, thickness, fill.
- Added BreakIndicators — shows the progress of every break in flight, yours and other players'.
- Added Breadcrumbs — draws the path you walked.
- Added ViewModel — hand and item positioning, per hand.
- Added HitEffects — damage numbers and hit particles that agree with the health bars.
- Added RainbowEnchant — recolours the enchantment glint.
- Improved HealthIndicators: reads confirmed damage and heal events from the shared `HealthChangeTracker`, so it and HitEffects can no longer disagree or double-count.
- Improved PlayerESP: optional stable box width, so a box does not breathe as a player turns.
- Improved Chams: can now tint your own held item.

**World**
- Added BaseFinder — flags chunks somebody has built in, from chunk data as it arrives: seven tiers of block evidence plus written signs, portals, spawners, skybuilds and deep builds. Finds persist per server and dimension. The scan is queued and budgeted by chunk section, so an elytra run down a highway stays smooth.
- Added StashFinder — records container clusters per server, dimension and chunk, with JSON/CSV export and a `.stashes` command.
- Added SpawnProofer — covers the ground LightOverlay marks; both ask the same classifier, so they cannot disagree. Light sources go out one per tick, since a torch's radius usually clears several remaining candidates.
- Added LiquidFiller — fills liquid source blocks in reach. Sources only: flowing liquid refills from its source.
- Added AutoSign — writes every sign you place with the text of the last one you wrote by hand. Updates leave on a queue with a delay, because 2b2t rejects a sign update that lands too close behind the click that made the sign.
- Added AutoNametag — spends name tags on chosen entity types. The list starts empty on purpose.
- Added AutoMount — mounts the nearest rideable entity; sneaking, a spawn egg in hand, or an occupied mount all stop it.
- Added SpeedMine — faster breaking, sharing the mining lifecycle with Nuker, VeinMiner and the Printer.
- Added AutoSmelt — feeds and empties furnaces through the shared recipe automation.
- Improved Scaffold: rebuilt on `PlacementExecutor`, ~300 lines lighter for the same behaviour.
- Improved Nuker and VeinMiner: both moved onto the shared mining coordinator, so no two modules can run a second break lifecycle over the top of each other.
- Improved VillagerRoller: rolls against the shared recipe automation rather than its own click loop.

**Player**
- Added AutoArmor — equips the best armour by attributes, durability, enchantments and curses, and will not swap a nearly-broken elytra for a chestplate mid-flight.
- Added ElytraSwap — one key between chestplate and elytra.
- Added Offhand — priority-based offhand management: totem, contextual override, normal item.
- Added InventoryCleaner — throws what you do not want, never a slot you protected; preview and execution produce the same plan.
- Added ChestCleaner — the same idea aimed at a container.
- Added AutoCraft — crafts against a visible menu, with inventory reservation and output-space checks.
- Added AntiAFK — idle activity that yields to anything with a reason to move.
- Improved AutoEat: holds the use key through the shared input coordinator, and gives it up the moment something that outranks a meal wants the hand.

**Client**
- Added `.sprint` — a tick-by-tick recorder for the sprint flag: the value at `aiStep` entry and exit, the packet that actually went out, AutoSprint's own decision, and every write to the flag with the frames behind it. Off by default; stopping it writes the file. It is what found the AutoSprint bug above, after two reasoned fixes had missed it.
- Panic now releases the input and mining coordinators as well, so nothing is left holding a key or a half-finished break.

**Internals**
- New shared owners: `PlacementExecutor` (Surround, Scaffold, HoleFill, Burrow, AutoTrap, SpawnProofer, LiquidFiller), `MiningActionCoordinator` + `MiningTracker` (SpeedMine, BreakIndicators, AutoTool, Nuker, Printer, VeinMiner), `InputActionCoordinator` (AntiAFK, AutoWalk, AutoEat, AutoSprint), `RecipeAutomation` (AutoCraft, AutoSmelt), `HealthChangeTracker` (HealthIndicators, HitEffects).
- New shared classifiers: `HoleUtil` (HoleESP, HoleFill, Burrow, AutoTrap), `SpawnUtil` (LightOverlay, SpawnProofer), `EquipmentScorer` + `InventoryPolicy` (AutoArmor, ElytraSwap, InventoryCleaner, ChestCleaner).
- `WorldRecordStore` — per-server, per-dimension, per-chunk records with atomic writes, tolerant of old or malformed files. Backs StashFinder and BaseFinder.
- BaseFinder's block signatures were extracted from the reference implementation and validated id-by-id against 26.2's own registry: 471 of 472 verbatim, the odd one out a typo in the original.
