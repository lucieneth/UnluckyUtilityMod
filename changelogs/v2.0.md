**Unlucky Client 2.0** — MC 26.2 / Fabric.

**ClickGUI**
- Added Future style, picked in Theme → ClickGUI style.
- Added Color setting for the Future accent.
- Added panel-clipped blur.
- Fixed controls inside Future's glass using the Skeet accent.
- Toolbar now spans ClickGUI, HUD editor, Configs, Console and Friends, and returns you to where you opened it from.

**HUD editor**
- Added widget duplication — an independent copy with its own settings and position, kept across restarts.
- Added a tool rail: align, centre, lock, hide, reset position, duplicate.
- Added a widget list panel: left-click toggles, right-click opens settings, drag to move.
- Added a placement grid and safe-area guides for chat, hotbar, boss bars, potions and the scoreboard.
- Added snapping to edges, centres and other widgets. Hold Ctrl for pixel placement.
- Added preview data, so widgets that are empty at rest can still be placed.
- Settings popup now carries sliders, colour pickers and text fields inline.

**HUD styling**
- Added panel opacity, radius, border and border opacity.
- Added animated accent bars, with speed and direction.
- Added per-widget scale, padding, opacity, anchor and anchor margin.
- Added per-widget Fade, Slide or Scale transitions, with direction and speed.
- Added per-widget background and border modes.

**HUD widget settings**
- ArmorHUD: horizontal, vertical or grid layout, grid columns, durability text, item names, enchant abbreviations.
- ArrayList: sort, order, backdrop mode, spacing, category/bind suffix, category separators, colour mode with saturation and RGB speed, toggle animation and speed.
- Brewing: progress style, compact mode, queue and location row limits, success and error colours.
- Coords: layout, decimals, world axis, chunk coordinates, dimension.
- Info: biome, coordinates, facing, speed, server, dimension.
- Item pickups: history size, card or compact style, text colour.
- Keystrokes: WASD/ZQSD/Arrows labels, animation speed, CPS graph, scroll.
- Layers and Materials: sort, row spacing, active and complete colours.
- Player model: background, rotation, idle animation, cape, lighting, name, health, scale, crop.
- Potion HUD: sort, grouping, display mode, timer, timer bar, beneficial and harmful colours.
- Printer: progress style, success and error colours, auto-hide with delay.
- Radar: entity colours, dot size, marker opacity, proximity fade.
- Speedometer: layout, graph style, graph scale and maximum, smoothing.
- Target HUD: layout, model scale, health format, distance, ping, absorption, health-bar colour, hurt animation, gear durability.
- Watermark: style, name style, custom name, icon, version, server, FPS, ping, accent line and side.

**Modules**
- Added Auto switch and Switch back to Aura — picks a weapon from the hotbar before attacking, then returns to your slot.
- Improved Freecam: F5 shows a spectator head at the camera while your real body stays where it is.
- Improved Friends: the tablist mark is now a corner badge on the player's face, shared with the locator bar, compass and nametag heads. Falls back to colouring the name on cracked servers.
- Improved AutoSprint: no longer sends a sprint start and stop every tick against a wall, on empty hunger or in shallow water.
- Improved InventoryMove: arrow-look runs per frame instead of at 20 Hz, so the camera no longer snaps.

**Chat**
- Added completion for client dot commands: modules, binds, friends, waypoints, registry, stash and printer base. Vanilla chat and slash commands are untouched.

**Fixed**
- Crash opening the HUD editor from the main menu.
- Crash toggling a module, or opening the block or item picker, from the main menu.
- Crash when a blurred HUD widget met a blurred menu ("Can only blur once per frame").
- Media keys triggering every unbound module, and clearing a bind when bound to one.
- Printer stash list silently cut off after five chests.
- Configs, Console and Friends losing the toolbar under Future.
- `Invalid path in mod resource-pack unlucky` logged on every launch.
