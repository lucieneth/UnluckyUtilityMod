**Unlucky Client 2.0** — a second ClickGUI, a HUD editor you can actually lay a HUD out in, and chat that completes our own commands. Minecraft 1.21.11 (26.2), Fabric.

---

Added ClickGUI Future style. A second renderer picked in **Theme → ClickGUI style**, sitting beside the existing Skeet-style one. It deliberately shares no layout code — Future's identity is every category on screen at once — but both styles drive the same settings, so nothing behaves differently depending on which one you look at.
- Added Color setting. One accent drives the whole look: the glass keeps your hue but drops its saturation and brightness, so aqua gets a dark aqua backing rather than a fully saturated copy of itself.
- Added panel-clipped Blur. Minecraft only allows one blur per frame, so the stock full-frame blur is captured and replayed through a scissor rectangle per category column — the panels blur, the world behind them does not.
- Fixed every control inside Future's glass being themed by the wrong client. Checkboxes, sliders, dropdown marks and bind rows read the active style's accent now instead of reaching for the Skeet gradient by hand.
- The top toolbar is shared by ClickGUI, HUD editor, Configs, Console and Friends, and it remembers the screen you came from — including the title screen.

Improved HUD editor.
- Added widget duplication. A copy is a fully independent widget with its own settings and position, and it survives a restart; several copies of the same widget no longer overwrite each other in the config.
- Added a tool rail: align left/centre/right, top/middle/bottom, lock placement, hide, reset position, duplicate, preview data, grid and guides.
- Added a widget list panel. Left-click toggles a widget, right-click opens its settings, and the panel itself drags and scrolls.
- Added a placement grid and safe-area guides for the chat, hotbar, boss bars, potion icons and scoreboard, so nothing gets parked where vanilla will draw over it.
- Added edge, centre and stack snapping with guide lines. Hold **Ctrl** for pixel-exact placement.
- Added preview data, so widgets that are empty at rest (pickups, target HUD, printer) still show something to position.
- The right-click settings popup now carries sliders, colour pickers and text fields inline, scrolls, and hides rows that don't apply.

Added shared HUD styling, in the HUD module.
- Added Panel opacity, Panel radius, Panel border and Border opacity settings.
- Added animated accent bars with Speed and Direction settings.
- Every widget gained Scale, Padding, Opacity, Anchor and Anchor margin.
- Added per-widget transitions: Fade, Slide or Scale, with direction and speed.
- Added per-widget Background and Border modes, so a widget can opt out of the shared panel or wrap itself in one.

Added settings to every HUD widget. The editor generates its rows from the widget itself, so nothing is unreachable any more.
- **ArmorHUD**: Horizontal, Vertical or Grid layout, grid columns, durability text (percent or remaining), item names, abbreviated enchantments.
- **ArrayList**: sort by width, name or category; normal or reverse order; per-row, grouped or no backdrop; spacing; category or bind suffix; category separators; colour mode with saturation and RGB speed; Slide, Fade or no toggle animation with its own speed.
- **Brewing**: progress as text, bar or both; compact mode; queue and location row limits; success and error colours.
- **Coords**: full, compact or single-line layout; decimal precision; world axis; chunk coordinates; dimension.
- **Info**: biome, coordinates, facing, speed, server and dimension lines.
- **Item pickups**: history size, card or compact style, text colour.
- **Keystrokes**: WASD, ZQSD or Arrows labels; press animation speed; CPS graph; scroll direction.
- **Layers** and **Materials**: sort by count or name, row spacing, active and complete colours.
- **Player model**: panel, gradient or transparent background; follow, static or spinning rotation with a static angle; idle animation and speed; cape; normal, bright or dim lighting; name; health; scale; full, upper or head crop with a vertical offset.
- **Potion HUD**: sort by duration, name or type; grouping; full, text or icon display; timer and timer bar; separate beneficial and harmful colours.
- **Printer**: progress style, success and error colours, auto-hide with a delay.
- **Radar**: player, hostile and passive colours; dot size; marker opacity; proximity fade.
- **Speedometer**: normal or compact layout; line or bar graph; auto or fixed scale with a maximum; smoothing.
- **Target HUD**: compact, classic or detailed layout; model scale; health as number, percent or both; distance; ping; absorption; health-bar colour; flash, shake or pulse hurt animation; gear durability as bars, percentages, both or neither.
- **Watermark**: classic, minimal or pill style; brand, abbreviated, cased or custom name; icon; version; server; FPS; ping; animated accent line with a side setting.

Added chat completion for client commands. Typing a dot command now suggests as you type, with arrow keys and Tab to pick. Module names, binds, friends, waypoints, registry, stash and printer-base arguments all complete. Vanilla chat and slash commands are untouched — the suggestion list only ever appears for our own syntax.

Improved Freecam. F5 now shows a translucent spectator head at the camera the way vanilla does, while your real body stays rendered at its actual position in the world rather than being dragged along with the camera. First person keeps no proxy at all, exactly like vanilla.

Improved Friends. The tablist mark rides on the player's face as a corner badge instead of taking width in front of their name, and the same badge is now used by the locator bar, the compass strip and nametag heads. On cracked servers, where vanilla draws no tablist faces, the mark falls back to colouring the name so friends never silently lose it.

Added Auto switch to Aura, with a Switch back setting. It picks a weapon out of the hotbar before attacking and returns to your previous slot afterwards. The attack on the switching tick is skipped on purpose: a slot change only reaches the server on the next tick's sync, so hitting immediately would land with the old item.

Improved AutoSprint. It now mirrors vanilla's own cancel conditions instead of re-asserting the sprint flag on top of them. Walking into a wall, running out of hunger or wading through shallow water used to produce a START_SPRINTING and a STOP_SPRINTING every tick, for as long as you leaned on the block.

Improved InventoryMove arrow-look, which now runs per rendered frame instead of at 20 Hz. The camera visibly snapped before; "degrees per tick" still means the same thing at any frame rate.

Fixed a crash when opening the HUD editor from the main menu. 26.2 binds item components on the registry only once a world has synced them, so building any item stack on the title screen threw — the editor died on the diamond in its pickup preview. The toast icons shown when toggling a module, and the block and item pickers, went the same way.

Fixed a crash when a blurred HUD widget met a blurred menu ("Can only blur once per frame"). A frame allows exactly one blur, and both wanted it; the HUD now stands down for the screen on top of it, which costs nothing visually because that screen blurs the whole frame anyway.

Fixed media and consumer keys breaking binds. GLFW reports them as an unknown key, which is also our unbound sentinel — binding one used to match every unbound module at once, and pressing one while rebinding could silently clear the bind.

Fixed the printer stash list being cut off at 64 characters, which is exactly five chests. The truncated coordinate still parsed, so the survey lap flew hundreds of blocks to a chest that had never been there.

Fixed `Invalid path in mod resource-pack unlucky` appearing in the log on every launch.

Fixed Configs, Console and Friends losing the shared toolbar under the Future style.
