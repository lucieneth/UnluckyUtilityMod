**Unlucky Client 2.4** — MC 26.3 / Fabric. 190 modules.

**Client**
- Updated to Minecraft 26.3. Players staying on 26.2 keep 2.3.1, which continues on its own branch.
- Keybinds carry over: 26.3 renumbered every key, so the first launch converts binds saved by earlier versions once — the main config and every profile you load or import. Binds on numpad `/` and `-` have no 26.3 equivalent and come back unbound instead of silently landing on another key.
- Config import/export and the skin picker use the system file dialog through the game's new window layer, and no longer hold a thread open while it is up.

**Combat**
- Fixed Criticals' Packet mode on 26.3: the hop now goes up in one tick and down in the next, with the hit right behind it, so it lands one tick later than before — and actually crits. 26.3 servers accept one position per tick, and the old same-tick hop only ever reached them halfway.
- Fixed LegitMaceKill and BlatantMaceKill the same way: climb, then fall and hit, then land, one tick each. If the target is gone before the hit can go out, the spoof steps back down in short drops instead of landing the whole height as fall damage.
- Swings use the held item's own animation, so a spear stabs instead of whacking when a module attacks with it.

**Movement**
- 26.3 servers disconnect a client that sends more than one position in a tick. The client now enforces that limit itself, so no module combination can get you kicked with "invalid player movement".
- Blink releases its queue one position per tick instead of all at once — the server replays your path rather than receiving it in one burst.
- EventlessFly no longer sends its out-of-bounds packet, which 26.3 servers would kick for; it flies on its own positions alone.

**Player**
- InfiniteInteract reaches one packet step past vanilla — up to about 12 blocks with the maximum step — instead of walking a long path, which 26.3 servers no longer accept in one tick. It stays in place while you keep breaking or attacking and steps back once you stop. Maximum steps and Maximum range are gone.
- AutoBrew plans from the game's built-in brewing recipes. 26.3 no longer sends brewing recipes to the client, so a server's custom brews cannot be planned.

**Render**
- RainbowEnchant now colours every glint variant 26.3 draws, including the special item and armour variants the old check missed.
